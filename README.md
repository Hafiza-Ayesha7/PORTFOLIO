# Ayesha — Responsive Single-Page Portfolio

A responsive single-page portfolio and profile website built with semantic HTML5, modern CSS (Flexbox, CSS Grid, glassmorphism, dark/light theme variables, and media queries), and vanilla JavaScript, featuring a custom SVG logo, profile photo slot, experience, volunteer work, education, courses, certificates preview modal, skills, and projects.

## Sections Included

- **Hero & Navigation:** Fixed glassmorphic header with custom SVG logo mark, dark/light theme toggle, smooth anchor navigation, profile photo, and a responsive mobile drawer menu.
- **About & Role Highlights:** Overview of Software Engineering Technology studies, web development focus, and graphic/UI design work.
- **Experience:** Internships, engineering and design roles, leadership fellowships, and teaching/community roles with certificate/credential buttons.
- **Volunteer Work:** Ambassador, moderation, hosting, outreach, and community volunteer positions.
- **Education:** Academic degrees, school qualifications, and technical/design training courses.
- **Certificates:** Dedicated showcase of course, fellowship, and internship certificates with an interactive modal preview.
- **Skills:** Numbered cards covering HTML, CSS, JavaScript, Python, Flask, Git & GitHub, Figma, and Illustrator.
- **Projects:** Featured cards for *Bicycle Admin Dashboard*, *KarigarHub*, *Personal Portfolio*, and *Social Media Designs*.
- **Contact & Footer:** Direct email link, GitHub, and LinkedIn links.
